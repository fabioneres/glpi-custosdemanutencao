# Documentacao - GLPI 11

Esta pasta acompanha a linha GLPI 11 do Custos de Manutencao, a partir da
versao `2.0.0-alpha.1`.

- [Manual de uso](manual-de-uso.md)
- [Historico de alteracoes](../CHANGELOG.md)

Os PRDs, checklists e relatorios de sessao mantidos na arvore de
desenvolvimento registram a linha GLPI 10 e a integracao com FormCreator. Eles
nao devem ser usados como instrucao de instalacao ou homologacao desta variante
GLPI 11.
